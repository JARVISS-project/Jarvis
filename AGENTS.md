# Contribuir com o JARVIS

O LLM interpreta. O código autoriza. A Tool executa. A Skill lembra o procedimento.

- Nenhum prompt, memória, nota ou modelo concede autoridade operacional.
- Preserve prepare -> authorize -> bind -> execute -> verify -> audit.
- Autenticação não concede permissão de escrita; leitura não implica escrita.
- Efeitos externos passam pelas Tools e pelos controles existentes.
- Nunca registre ou versione credenciais, dados de usuário, modelos ou logs locais.
- Cada instalação pertence ao seu usuário: nenhuma pasta pessoal é predefinida.
- Integrações e serviços externos permanecem opcionais e dependem de configuração.
- Preserve alterações locais; faça mudanças pequenas e testes proporcionais.
- Testes usam perfis temporários e efeitos simulados, sem microfone ou contas reais.
- Mudanças em autorização, confirmação e arquivos devem testar aceitação e recusa.
- Não publique artefatos sem revisar dados pessoais, licenças e fontes correspondentes.
